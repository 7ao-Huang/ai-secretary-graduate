# MyFlow OS

这是一个从零开始搭建的 AI 智能秘书网站第一版骨架，重点围绕以下几件事：

- 帮你处理重复、繁杂、容易浪费时间的事务
- 自动管理重要日程，并在冲突时按优先级重排
- 聚合多个邮箱并判断哪些邮件值得回复或转成待办
- 根据你的状态给出成长建议与线下活动建议
- 用站内提醒先把电脑端体验做好

## 当前页面

- `首页`：月历优先的秘书工作台，默认显示整月重要事项
- `收集`：作为待整理入口
- `任务`：统一管理待办与待回复事项
- `计划`：日、周、月三个层级
- `邮件智能中心`：多邮箱接入状态、分析结果、分类规则
- `回顾`：用于总结执行情况和调整策略

## 首页重点

- `月历视图`：只显示会议、截止日、出行、考试、上课、电影、演唱会和手动加入的重要事项
- `当日流程`：展示完整一天，包括学习块、健身、邮件触发的会议和自动改期结果
- `站内提醒`：在发现冲突或新增重要变化时即时提醒
- `快速加入新行程`：支持手动加入新的重要活动
- `AI 秘书建议`：根据你的毕业与求职阶段，建议学习安排与适合参加的线下活动

## 当前交互演示

- 演示了“导师 15:00 临时开会”后，系统自动把原定 15:00 的健身改到 16:00
- 演示了 AI 为你补上学习时间块
- 演示了 AI 推荐招聘会，并支持一键加入日程

## 演示接口

- `GET /api/email-digest`

这个接口目前返回演示数据，用于表示未来真实的邮件聚合与摘要结果。

## 下一步建议

1. 接入真实认证：
   Gmail 和 Outlook 优先走 OAuth，自定义域名邮箱走 IMAP。
2. 建立邮件同步服务：
   定时拉取新邮件，保存发件人、主题、时间、线程和正文摘要。
3. 增加邮件分析规则：
   判断是否需要回复、是否包含截止时间、是否适合转成任务。
4. 接入通知：
   先保留网站内提醒，再扩展浏览器通知和手机端提醒。
5. 加入持久化：
   推荐使用 `PostgreSQL` 或 `Supabase`。
6. 增加日程调度引擎：
   在新增邮件、手动添加活动或外部日历同步时，自动寻找合理空档并按优先级调整事项。

## 数据说明

当前页面主要使用这两份演示数据：

- `lib/mock-data.ts`
- `lib/secretary-data.ts`

目的是先确认 AI 秘书的产品结构、首页体验和自动调度方向，再逐步替换成真实数据源。
